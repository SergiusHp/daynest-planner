# Мій МЯУдень 🐱

Одно-файловий веб-застосунок-планер: день → тиждень/місяць → фокус-таймер з музикою.

- Застосунок: `index.html` (відкривається й локально, без збірки)
- Музика фокусу: `audio/focus-1.mp3`, `audio/focus-2.mp3` (треба тримати поруч з `index.html`)
- Дані зберігаються в localStorage браузера
- Свайп по справі зліва направо — виконано / повернути; кнопка-нота на сторінці «Фокус» вмикає й вимикає музику
