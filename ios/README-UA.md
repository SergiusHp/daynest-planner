# Мій МЯУдень — iOS-застосунок

Нативний застосунок для iPhone на **SwiftUI** (iOS 17 і новіші). Повністю переписаний з веб-версії: ті самі сторінки, жести, ілюстрації, шрифт Nunito, музика для фокусу — але з можливостями справжнього iPhone-застосунку.

## Що вміє

- **Привітання й знайомство** (лише при першому запуску): три анімовані кроки — сонечко, свайп, котик.
- **Сьогоднішні справи**: тиждень угорі, список справ, котик унизу. Торкання котика — «Новий план». Свайп по справі **зліва направо** — закреслити котячими подряпинами (4 випадкові стилі) або повернути. Сонечко повертає на сьогодні.
- **Нагадування** за 5/15/30/45/60 хв до плану — **приходять навіть коли застосунок закритий** (локальні сповіщення iOS).
- **Тиждень / місяць**: календар і невиконані плани вибраного дня чи тижня.
- **Фокус**: циферблат-котик, лапку крутять пальцем (1–60 хв), пресети, вибір справи, музика (грає й із заблокованим екраном), сповіщення про кінець сесії, лічильник сесій за день.
- Тактильний відгук (Taptic Engine), підтримка VoiceOver, «Зменшити рух» і збільшеного тексту.
- Дані зберігаються лише на пристрої (жодних серверів і збору даних).

## Структура папки

```
MyauDen.xcodeproj        ← відкривати цей файл у Xcode
MyauDen/
  App/          вхід у застосунок, потік запуску, гортання сторінок
  Model/        плани, дати, фокус-таймер, збереження
  Services/     сповіщення, вібрація, музика
  Theme/        кольори, шрифти, векторні контури
  Views/        екрани: Welcome, Onboarding, Day, Calendar, Focus, Sheet
  Resources/    ілюстрації, іконка, шрифти, музика, маніфест приватності
MyauDenUITests/ автоматичні тести жестів і сценаріїв
tools/          скрипти, що згенерували проєкт і векторні контури
```

## 1. Запуск на Mac (без акаунта розробника — безкоштовно)

1. Встановіть **Xcode** з Mac App Store (потрібна найновіша версія; для відправки в App Store Apple вимагає збирати останнім Xcode).
2. Скопіюйте папку «Котодень для IOS» на Mac і двічі клацніть **MyauDen.xcodeproj**.
3. Угорі оберіть симулятор, наприклад **iPhone 16**, і натисніть ▶︎ (Cmd+R).
4. Щоб поставити на **свій iPhone**: підключіть телефон кабелем → у Xcode зліва клацніть проєкт **MyauDen** → вкладка **Signing & Capabilities** → **Team**: додайте свій Apple ID («Add an Account…») і оберіть його. Якщо Xcode скаже, що ідентифікатор зайнятий, змініть **Bundle Identifier** на свій, наприклад `com.vashe-imya.myauden`. На iPhone увімкніть **Параметри → Конфіденційність і безпека → Режим розробника**. Потім ▶︎.
   *З безкоштовним Apple ID застосунок працює на телефоні 7 днів, далі його треба перевстановити з Xcode.*

## 2. Акаунт Apple Developer (для App Store)

1. Відкрийте <https://developer.apple.com/programs/> → **Enroll**. Потрібні Apple ID з двофакторною автентифікацією та оплата **99 USD на рік**. Реєструватися зручніше з застосунку **Apple Developer** на iPhone.
2. Оберіть тип: **Individual** (фізична особа — у магазині буде ваше ім'я) або **Organization** (потрібен D-U-N-S номер компанії).
3. Підтвердження зазвичай займає від кількох годин до 2 днів.

## 3. Відправка в App Store

1. У Xcode: **Signing & Capabilities → Team** — оберіть команду платного акаунта.
2. На <https://appstoreconnect.apple.com> → **Apps → «+» → New App**: платформа iOS, назва «Мій МЯУдень» (якщо зайнята — додайте слово, напр. «Мій МЯУдень: планер»), мова — українська, Bundle ID — той самий, що в Xcode, SKU — будь-який (наприклад `myauden-1`).
3. У Xcode вгорі оберіть **Any iOS Device (arm64)** → меню **Product → Archive**. Після збірки відкриється **Organizer** → **Distribute App → App Store Connect → Upload**.
4. В App Store Connect заповніть сторінку застосунку:
   - **Скриншоти**: обов'язково для iPhone 6,9″ (наприклад, із симулятора iPhone 16 Pro Max: Cmd+S у симуляторі зберігає знімок).
   - Опис, ключові слова, категорія (**Продуктивність**), вікове обмеження (4+).
   - **Посилання на політику конфіденційності** (обов'язково) — підійде проста сторінка: «Застосунок не збирає жодних даних; усі плани зберігаються лише на пристрої».
   - **App Privacy**: «Data Not Collected» (застосунок нічого не збирає).
   - Розділ **Build**: оберіть завантажену збірку → **Submit for Review**.
5. Перевірка Apple зазвичай триває 1–3 дні. Перед цим можна роздати бета-версію друзям через **TestFlight**.

## Що варто знати

- **Ілюстрації** взяті з вашого аркуша зразків і мають невелику роздільну здатність. На великих екранах вони трохи м'якші; для найкращого вигляду в App Store варто замінити їх версіями у 2–3 рази більшими (файли в `Resources/Assets.xcassets`).
- **Іконку** зібрано з котика вашого логотипу (`AppIcon.appiconset/appicon-1024.png`, 1024×1024). Її можна замінити своєю — просто покладіть новий PNG з тим самим ім'ям.
- **Музика** (`Resources/Audio`) — переконайтеся, що маєте право поширювати ці треки в застосунку (ліцензія), інакше Apple може відхилити застосунок або власник прав подасть скаргу.
- Шрифт **Nunito** — вільна ліцензія SIL OFL (файл `Resources/Fonts/OFL-Nunito.txt`).
- Номер версії й збірки: проєкт → **General → Version / Build** (для кожного нового завантаження Build треба збільшувати).
